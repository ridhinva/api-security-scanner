# Contributing

Thank you for contributing! This project welcomes contributions from the security community.

## Ways to Contribute

- **Report bugs** — Open an issue with reproduction steps
- **Suggest features** — Open an issue with use case and motivation
- **Submit PRs** — Fix bugs, add features, improve docs
- **Improve documentation** — README, code comments, examples
- **Add tests** — Unit tests, integration tests, test cases

## Pull Request Process

1. Fork the repository
2. Create a feature branch: `git checkout -b feat/amazing-feature`
3. Make your changes with clear, focused commits
4. Follow conventional commits: `feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:`
5. Run linting: `flake8` (Python) or equivalent
6. Push and open a PR against `main`

## Code Style

- **Python**: PEP 8, type hints where practical, max line length 127
- **Commit messages**: Conventional Commits format
- **Documentation**: Update README for new features/flags

## Security Issues

**Do NOT open public issues for security vulnerabilities.**  
Report privately via GitHub Security Advisories or email: ridhinofficial@gmail.com

## Code of Conduct

Be respectful. No harassment, discrimination, or abusive behavior.  
This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
